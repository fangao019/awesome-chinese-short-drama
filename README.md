## 什么是竖屏短剧

竖屏短剧（又称微短剧、小程序剧）指以 9:16 竖屏形态拍摄、单集 1–3 分钟、整部数十至上百集的连续剧。
近年在中文互联网快速增长，题材以都市、古装、玄幻、霸总、甜宠为主，主要在手机端观看。

## 相关概念

- **微短剧 / 小程序剧**：以微信小程序等载体分发的短剧形态。
- **竖屏剧**：原生 9:16 构图的剧集，与传统横屏剧在分镜与节奏上差异明显。
- **剧情共创**：观众参与剧情走向讨论、影响后续内容的互动形式。
